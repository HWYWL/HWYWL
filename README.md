# YI

**广州开发者 | Java & 大数据 | 单片机与鸿蒙爱好者**

自 2016 年加入 GitHub 以来，主业写 Java 后端，副业折腾大数据和单片机。喜欢把脑子里的想法真的跑起来——从 51 单片机上的微内核，到鸿蒙版的 OpenWrt 管理 App，再到给飞牛 NAS 写的一堆小工具。目前公开维护 64 个仓库，累计收获 240+ Star。

---

## 👨‍💻 关于我

- 🌏 **所在地**：China · Guangzhou
- 🔗 **个人网站**：https://hwy.ac.cn
- 📅 **GitHub 成员**：2016 年至今
- 🛠️ **技术方向**：Java / Spring Boot、Go、Python、C/C++、大数据、ArkTS（鸿蒙）
- 🔥 **近期折腾**：鸿蒙版 OpenWrt 管理 App（iStore）、飞牛 NAS 工具链、51 单片机微内核（YI51-OS）
- 🏗️ **贡献风格**：以独立构建为主，偏好交付「能跑起来」的完整实现
